# Debug Fighter Web MVP

React + TypeScript + Phaser 기반의 웹 액션 로그라이크 게임입니다.

## 실행 방법
1. 의존성 설치
```bash
npm install
```

2. 개발 서버 실행
```bash
npm run dev
```

3. 프로덕션 빌드
```bash
npm run build
```

4. 빌드 결과 확인
```bash
npm run preview
```

## 디렉터리 구조
```text
src/
  main.tsx
  App.tsx
  styles.css
  game/
    constants/
    core/
    data/
    scenes/
    services/
    shared/
    systems/
```

## 조작 키
- `WASD`: 이동
- `마우스`: 조준
- `Space`: 공격
- `Enter`: 게임 시작
- `R`: 로비 복귀
