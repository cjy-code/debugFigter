# 카르마 개선 설계

## 목표

- 초반 카르마 구조는 복잡한 레시피 성공/실패보다 속성별 성장과 전투 체감에 집중한다.
- 뱀파이어 서바이벌류의 공격 스킬 선택/성장 구조를 카르마 시스템으로 대체한다.
- 카르마 획득 시 해당 속성 경험치가 증가한다.
- 속성 경험치가 요구치를 넘으면 해당 카르마 레벨이 오른다.
- 카르마 레벨업은 속성 효과의 개수와 데미지를 올린다.
- 여러 속성을 동시에 보유하면 각 속성 효과가 독립적으로 동작해 자연스럽게 조합 빌드가 된다.
- 1차 카르마 시스템에서는 특정 레벨 이후의 융합은 개발하지 않고, 융합 직전까지의 성장 구조만 만든다.

## 1차 개발 범위

1차 카르마 시스템은 공격 스킬을 대체하는 성장형 자동 전투 시스템이다.

포함:

- 카르마 에셋 드랍
- 카르마 획득 시 후보 3개 중 1개 선택
- 최대 3종 카르마 선택 제한
- 선택한 카르마별 경험치 획득
- 카르마별 레벨업
- 레벨업에 따른 데미지, 개수, 범위, 쿨다운 성장
- 직업별 카르마 보정
- 카르마별 자동 공격 발동
- 카르마 드랍률 설정

제외:

- 카르마 융합
- 융합 카르마 색상/에셋 제작
- 융합 후 신규 스킬
- 융합 레시피
- 융합 성공/실패 확률

융합은 2차 개발 범위로 분리한다.

## 카르마 속성

초반 기본 속성은 3종으로 제한한다.

| 속성 | 컨셉 | 핵심 성능 | 전투 역할 |
| --- | --- | --- | --- |
| 불꽃 | 불 채찍 휘두르기 | 데미지, 타격 범위 | 근접 광역 정리 |
| 전기 | 체인식 전기 공격 | 연쇄 개수, 공격 속도 | 다수 대상 연쇄 처리 |
| 바위 | 캐릭터 주위를 도는 바위 | 바위 개수, 충돌 데미지, 방어 | 접근 방어 및 지속 충돌 |

## 공통 성장 규칙

카르마는 `count` 중심이 아니라 `exp`, `level`, `damage`, `projectileCount` 중심으로 관리한다.

```ts
type KarmaElementId = "fire" | "electric" | "rock";

type KarmaElementState = {
  id: KarmaElementId;
  level: number;
  exp: number;
  requiredExp: number;
  damage: number;
  count: number;
};
```

획득 처리:

1. 카르마 구슬에 `karmaId`와 `expValue`를 저장한다.
2. 획득 시 `karmaStates[karmaId].exp += expValue`를 적용한다.
3. `exp >= requiredExp`면 레벨업을 반복 처리한다.
4. 레벨업마다 `damage`, `count`, 속성별 보조 수치를 갱신한다.

요구 경험치:

| 레벨 | 필요 경험치 |
| --- | --- |
| 1 -> 2 | 3 |
| 2 -> 3 | 6 |
| 3 -> 4 | 10 |
| 4 -> 5 | 15 |
| 이후 | `이전 요구치 + 5` |

초반 밸런스는 빠른 체감을 위해 1레벨부터 효과를 활성화한다.

## 불꽃 카르마

컨셉: 플레이어 시선 방향 또는 가장 가까운 적 방향으로 불 채찍을 휘두른다.

동작:

- 일정 쿨다운마다 부채꼴/짧은 호 형태의 타격 영역을 생성한다.
- 타격 영역 안의 적에게 불꽃 데미지를 준다.
- 레벨이 오르면 채찍 줄기 수와 데미지가 증가한다.

성장:

| 레벨 | 채찍 수 | 데미지 배율 | 추가 효과 |
| --- | --- | --- | --- |
| 1 | 1 | 1.00 | 기본 전방 휘두르기 |
| 2 | 1 | 1.25 | 범위 소폭 증가 |
| 3 | 2 | 1.45 | 좌우 2연격 |
| 4 | 2 | 1.75 | 화상 틱 데미지 추가 |
| 5 | 3 | 2.10 | 넓은 3연격 |

구현 기준:

- 기본 데미지: `player.damage * fire.damageMultiplier`
- 기본 쿨다운: 900ms
- 기본 사거리: 120px
- 범위 처리는 타격 순간에만 계산해 지속 충돌 오브젝트 수를 늘리지 않는다.

## 전기 카르마

컨셉: 가장 가까운 적을 맞춘 뒤 주변 적에게 체인식 전기 공격이 튄다. 전기 레벨은 공격 속도도 올린다.

동작:

- 일정 쿨다운마다 가장 가까운 적 1명을 첫 대상으로 잡는다.
- 첫 대상 주변에서 다음 대상을 찾고, 이미 맞은 대상은 제외한다.
- 연쇄 횟수만큼 반복하며 각 대상에게 전기 데미지를 준다.
- 레벨이 오르면 체인 수, 데미지, 공격 속도가 증가한다.

성장:

| 레벨 | 체인 수 | 데미지 배율 | 공격 속도 보정 |
| --- | --- | --- | --- |
| 1 | 2 | 0.80 | 0% |
| 2 | 3 | 0.95 | 5% |
| 3 | 4 | 1.10 | 10% |
| 4 | 5 | 1.25 | 15% |
| 5 | 6 | 1.45 | 20% |

구현 기준:

- 기본 쿨다운: 700ms
- 체인 탐색 거리: 160px
- 공격 속도 보정은 전기 카르마 스킬 쿨다운에 우선 적용하고, 필요 시 공통 자동 공격 쿨다운에도 일부 반영한다.
- 연쇄 탐색은 몬스터 수가 많을 수 있으므로 매 체인마다 전체 정렬하지 말고 가장 가까운 후보 1개만 선형 탐색한다.

## 바위 카르마

컨셉: 캐릭터 주위를 도는 바위가 방어막처럼 움직이며 적과 부딪히면 데미지를 주고 사라진다. 사라진 바위는 일정 시간 뒤 하나씩 재생성된다.

동작:

- 플레이어 주변 궤도에 바위 오브젝트를 배치한다.
- 바위는 플레이어 위치를 중심으로 회전한다.
- 적과 충돌하면 해당 적에게 데미지를 주고 바위는 비활성화된다.
- 비활성화된 바위는 재생성 대기열에 들어가고, 일정 시간이 지나면 하나씩 다시 활성화된다.

성장:

| 레벨 | 최대 바위 수 | 데미지 배율 | 재생성 시간 |
| --- | --- | --- | --- |
| 1 | 1 | 0.90 | 3.5초 |
| 2 | 2 | 1.00 | 3.2초 |
| 3 | 2 | 1.20 | 2.8초 |
| 4 | 3 | 1.35 | 2.5초 |
| 5 | 4 | 1.55 | 2.2초 |

구현 기준:

- 바위는 지속 오브젝트라서 최대 개수 제한이 중요하다.
- 충돌 후 즉시 `destroy`하지 않고 비활성 상태로 전환하면 재생성 비용을 줄일 수 있다.
- 바위 충돌은 플레이어 피격 판정과 별개로 처리한다.
- 바위가 살아 있는 동안 접근 몬스터를 먼저 맞추므로 방어 체감이 생긴다.

## 융합 전 조합 방식

초반에는 별도 레시피 성공/실패를 제거하고, 보유 레벨 합산으로 약한 조합 보정만 만든다. 이 조합 보정은 최종 융합이 아니라 1차 시스템의 임시 시너지다.

| 조합 | 조건 | 효과 |
| --- | --- | --- |
| 불꽃 + 전기 | 불꽃 Lv2 이상, 전기 Lv2 이상 | 불 채찍 타격 시 20% 확률로 전기 체인 1회 추가 |
| 전기 + 바위 | 전기 Lv2 이상, 바위 Lv2 이상 | 바위 충돌 시 주변 1명에게 전기 전이 |
| 바위 + 불꽃 | 바위 Lv2 이상, 불꽃 Lv2 이상 | 바위 충돌 위치에 짧은 화염 폭발 |
| 삼속성 | 세 속성 모두 Lv3 이상 | 모든 카르마 데미지 15% 증가 |

조합은 별도 UI 선택 없이 조건 충족 시 자동 활성화한다. 초반 구현 난이도를 낮추기 위해 조합 효과는 패시브 보정으로만 둔다.

주의:

- 이 단계의 조합은 융합이 아니다.
- 카르마 색상이 바뀌거나 새로운 카르마로 합쳐지지 않는다.
- 선택한 카르마 3종은 각각 독립 자동 스킬로 유지된다.

## 데이터 구조 변경안

기존:

- `karmaCounts`
- `karmaBuild`
- 레시피 성공/실패
- 슬롯 제한

변경:

- `karmaElements`
- 속성별 `level`, `exp`, `damage`, `count`
- 속성별 스킬 런타임 상태
- 자동 조합 패시브

```ts
type PlayerState = {
  // 기존 필드 유지
  karmaElements: Record<KarmaElementId, KarmaElementState>;
  activeKarmaSynergies: KarmaSynergyId[];
};
```

## 구현 순서

1. `KarmaId`를 초반용 `fire | electric | rock` 중심으로 정리한다.
2. `karmaCounts`, `karmaBuild`를 대체할 `karmaElements` 상태를 추가한다.
3. 카르마 구슬 흡수 로직을 수량 증가가 아니라 경험치 증가로 바꾼다.
4. `KarmaSystem`에 경험치 증가, 레벨업, 성장 수치 계산 함수를 추가한다.
5. `StageScene`에 불꽃/전기/바위 업데이트 루프를 분리해 추가한다.
6. HUD는 속성별 `Lv`, `EXP`, 핵심 수치만 보여준다.
7. 기존 레시피 성공/실패 보정 함수는 제거하거나 비활성화한다.
8. 테스트는 카르마 경험치 증가, 레벨업, 수치 증가, 바위 재생성, 전기 체인 대상 중복 방지 위주로 작성한다.

## MVP 기준

- 불꽃, 전기, 바위 3종만 드랍된다.
- 카르마 구슬 1개는 해당 속성 경험치 1을 준다.
- 속성 레벨업 시 즉시 HUD와 전투 성능이 바뀐다.
- 불꽃은 휘두르기, 전기는 체인, 바위는 회전/소모/재생성이 각각 체감된다.
- 기존 카르마 슬롯과 레시피 확률은 초반 MVP에서 제외한다.
- 융합은 구현하지 않는다.

## 플레이 스타일 개선안

### 공격 타입 분리

기본 공격은 `singleHit`과 `multiHit`으로 분리한다.

| 공격 타입 | 설명 | 권장 사용처 |
| --- | --- | --- |
| 단일 타격 | 가장 가까운 적 1명에게 높은 피해를 준다. | 궁수, 마법사 단일 스킬, 보스 대응 |
| 다중 타격 | 범위 또는 여러 대상에게 낮거나 중간 피해를 준다. | 전사 기본 공격, 불꽃/바위 카르마 |

전사 기본 공격은 다중 타격으로 잡는다.

- 전사는 근접 진입 위험이 있으므로 여러 적을 동시에 정리하는 방향이 맞다.
- 현재 자동 공격의 `attackCount` 구조와 잘 맞아서 적용 가능성이 높다.
- 다만 전사만 다중 타격을 기본값으로 두려면 직업별 공격 프로필이 필요하다.

권장 데이터 구조:

```ts
type BasicAttackType = "singleHit" | "multiHit";

type PlayerClassProfile = {
  classType: PlayerClassType;
  name: string;
  description: string;
  maxHp: number;
  damage: number;
  attackRange: number;
  basicAttackType: BasicAttackType;
  baseAttackCount: number;
  color: number;
};
```

권장 기본값:

| 직업 | 공격 타입 | 타격 수 | 방향 |
| --- | --- | --- | --- |
| 전사 | 다중 타격 | 3 | 짧은 범위 내 가까운 적 3명 |
| 마법사 | 단일 타격 | 1 | 중거리 고피해 또는 추후 광역 스킬 |
| 궁수 | 단일 타격 | 1 | 긴 사거리 고정밀 공격 |

### 카르마 선택 제한

카르마는 최대 3종까지만 선택 가능하게 한다.

규칙:

1. 카르마 구슬을 획득하면 즉시 속성이 확정되지 않는다.
2. 랜덤 후보 3개를 띄우고 플레이어가 1개를 선택한다.
3. 이미 선택한 속성은 후보에 우선 포함될 수 있다.
4. 선택한 카르마 종류가 3개 미만이면 신규 속성도 후보에 등장한다.
5. 선택한 카르마 종류가 3개가 되면, 이후 후보는 선택된 3종 안에서만 나온다.
6. 최대 누적 이후에는 선택되지 않은 다른 종류의 카르마는 드랍 후보와 선택 후보에서 제외한다.

예시:

- 현재 선택 속성 없음: `불꽃 / 전기 / 바위` 중 3개 후보 표시
- 현재 선택 속성 `불꽃`: 후보는 `불꽃 + 신규 후보 2개`
- 현재 선택 속성 `불꽃, 전기`: 후보는 `불꽃 / 전기 / 신규 후보 1개`
- 현재 선택 속성 `불꽃, 전기, 바위`: 후보는 항상 `불꽃 / 전기 / 바위`

추후 속성 추가를 고려한 규칙:

- 전체 속성 풀은 확장 가능하게 유지한다.
- 선택 슬롯은 초반 기준 3개로 고정한다.
- 신규 속성이 추가되어도 이미 3종을 확정한 런에서는 나오지 않는다.
- 속성 추가 시 밸런스 영향은 후보 가중치와 선택 슬롯 수로 조절한다.

권장 데이터 구조:

```ts
type KarmaSelectionState = {
  selectedElementIds: KarmaElementId[];
  maxSelectedElementCount: number;
  pendingOptions: KarmaElementId[];
};
```

### 카르마 획득 플로우

기존의 카르마 구슬 획득은 바로 수량 증가 또는 경험치 증가로 이어진다. 개선 후에는 선택 UI를 한 번 거친다.

흐름:

1. 몬스터가 카르마 에셋을 드랍한다.
2. 플레이어가 카르마 에셋을 획득한다.
3. 게임을 일시 정지하거나 레벨업 UI처럼 선택 상태로 전환한다.
4. `KarmaSystem.pickKarmaOptions()`가 후보 3개를 생성한다.
5. 플레이어가 1개를 선택한다.
6. 선택한 속성의 경험치가 오른다.
7. 선택 속성 수가 3개 미만이고 신규 속성을 골랐다면 `selectedElementIds`에 추가한다.
8. 경험치가 충분하면 해당 속성이 레벨업한다.

권장 방향:

- 카르마 선택 UI는 기존 레벨업 선택 UI와 같은 이벤트 구조를 재사용한다.
- 초반에는 카르마 획득 1회당 경험치 1로 단순화한다.
- 추후 엘리트/보스 카르마는 경험치 2~3을 주는 식으로 확장한다.

### 조작감 개선

현재 이동은 입력이 없으면 속도를 즉시 0으로 만든다. 멈출 때 살짝 미끄러지는 느낌을 주려면 감속 기반 이동으로 바꾼다.

적용 가능 여부:

- 적용 가능하다.
- 현재 이동 속도는 상수 `PLAYER_SPEED = 260`으로 관리되고 있어 기본 속도 하향은 간단하다.
- 미끄러짐은 `setVelocity(0, 0)` 대신 목표 속도에 보간하거나 감속 계수를 적용하면 된다.

권장 수치:

| 항목 | 현재 | 권장 |
| --- | --- | --- |
| 기본 이동 속도 | 260 | 220 |
| 가속 반응 | 즉시 반영 | 0.18~0.25 보간 |
| 정지 감속 | 즉시 정지 | 0.82~0.88 감속 |
| 최소 속도 컷 | 없음 | 8 이하일 때 0 처리 |

권장 구현 방식:

```ts
const PLAYER_SPEED = 220;
const PLAYER_ACCELERATION_LERP = 0.22;
const PLAYER_DECELERATION_FACTOR = 0.86;
const PLAYER_STOP_SPEED_THRESHOLD = 8;
```

- 입력이 있으면 목표 속도 방향으로 현재 속도를 보간한다.
- 입력이 없으면 현재 속도에 감속 계수를 곱한다.
- 감속 후 속도가 임계값보다 작으면 0으로 고정한다.

주의점:

- 미끄러짐이 너무 강하면 적 충돌 회피가 불편해진다.
- 전사처럼 근접 플레이를 하는 직업은 정지 반응이 중요하므로 감속은 짧게 둔다.
- 넉백 상태와 일반 이동 감속이 충돌하지 않도록 넉백 중에는 기존 처리를 우선한다.

## 적용 가능 유무

| 항목 | 적용 가능성 | 난이도 | 판단 |
| --- | --- | --- | --- |
| 전사 기본 공격 다중 타격 | 가능 | 낮음 | 기존 `attackCount` 구조를 직업별 기본값으로 확장하면 된다. |
| 기본 공격 타입 분리 | 가능 | 중간 | 직업 프로필과 공격 처리 분기가 필요하다. |

| 카르마 획득 시 3개 후보 중 택1 | 가능 | 중간 | 기존 레벨업 선택 UI 흐름을 재사용하는 방향이 좋다. |

## 권장 구현 우선순위

1. 기본 속도 하향과 정지 감속을 먼저 적용한다.
2. 전사 기본 공격을 다중 타격으로 바꾼다.
3. 기본 공격 타입을 직업 프로필로 분리한다.
4. 카르마 선택 UI를 기존 레벨업 선택 UI 패턴으로 추가한다.
5. 카르마 최대 3종 제한과 후보 생성 규칙을 적용한다.
6. 불꽃/전기/바위 속성별 전투 효과를 순차 구현한다.

권장 방향은 조작감부터 먼저 잡는 것이다. 이동감과 전사 기본 공격 체감이 좋아져야 카르마 효과를 얹었을 때 빌드 차이가 더 명확하게 느껴진다.

## 카르마 자동 공격 스킬화

카르마는 패시브 보너스가 아니라 자동으로 발동되는 공격 스킬로 취급한다.

뱀파이어 서바이벌류 게임에서 플레이어가 공격 스킬을 고르고 레벨업시키는 구조를 이 프로젝트에서는 카르마가 대신 담당한다.

핵심 원칙:

- 기본 공격은 직업 정체성을 담당한다.
- 카르마는 자동 공격 스킬 슬롯을 담당한다.
- 카르마마다 별도 쿨다운, 대상 탐색, 타격 방식, 성장 수치를 가진다.
- 카르마 발현 주기는 플레이어 공격 속도 보정을 반영한다.
- 카르마마다 개별 피격 범위를 가진다.
- 카르마마다 개별 피격 대상 목록을 계산한다.
- 카르마 데미지는 해당 카르마의 피격 대상에게만 적용한다.
- 여러 카르마를 선택하면 여러 자동 스킬이 각자 쿨다운에 맞춰 발동한다.
- 카르마 레벨업은 해당 자동 스킬의 데미지, 개수, 쿨다운, 범위를 올린다.
- 1차에서는 카르마가 최대 레벨에 도달해도 다른 카르마와 합쳐지지 않는다.

권장 구조:

```ts
type KarmaAutoSkillState = {
  id: KarmaElementId;
  level: number;
  exp: number;
  baseCooldownMs: number;
  currentCooldownMs: number;
  nextCastAt: number;
  damageMultiplier: number;
  hitCount: number;
  range: number;
  hitboxRadius: number;
};
```

전투 루프 기준:

1. 매 프레임 선택된 카르마 목록을 순회한다.
2. 현재 시간이 `nextCastAt`보다 작으면 건너뛴다.
3. 공격 속도 보정을 반영해 `currentCooldownMs`를 계산한다.
4. 카르마별 피격 범위와 대상 탐색 로직을 실행한다.
5. 대상이 있으면 카르마 스킬을 발동한다.
6. 해당 카르마가 계산한 피격 대상에게만 데미지를 적용한다.
7. `nextCastAt = now + currentCooldownMs`로 갱신한다.

공격 속도 반영:

```ts
currentCooldownMs = baseCooldownMs * player.cooldownMultiplier;
```

주의:

- 공격 속도는 발현 주기에만 반영한다.
- 피격 범위와 피격 대상은 카르마별로 별도 계산한다.
- 한 카르마가 찾은 대상 목록을 다른 카르마가 재사용하지 않는다.
- 같은 몬스터가 여러 카르마 피격 범위에 들어오면 각 카르마 데미지를 각각 받을 수 있다.

### 카르마별 피격 판정

| 카르마 | 피격 범위 | 피격 대상 | 데미지 적용 |
| --- | --- | --- | --- |
| 불꽃 | 플레이어 전방 부채꼴/채찍 호 | 범위 안의 적, `hitCount`까지 | 범위 타격 데미지 |
| 전기 | 첫 대상 + 체인 탐색 반경 | 체인 경로에 잡힌 적 | 체인 순서별 데미지 |
| 바위 | 회전 바위 개별 충돌 반경 | 바위와 충돌한 적 | 충돌한 바위 1개당 데미지 |

불꽃:

- 발현 시점마다 전방 피격 범위를 새로 계산한다.
- `hitCount`가 1이면 가장 가까운 범위 대상 1명만 맞는다.
- `hitCount`가 2 이상이면 범위 안 대상 중 가까운 순서로 맞는다.

전기:

- 첫 대상은 탐색 사거리 안에서 가장 가까운 적이다.
- 이후 대상은 직전 대상 기준 체인 반경 안에서 찾는다.
- 같은 발현 안에서는 이미 맞은 대상에게 다시 튀지 않는다.

바위:

- 바위는 자동 쿨다운 발현이 아니라 상시 회전형 카르마로 처리한다.
- 공격 속도는 바위 재생성 또는 충돌 후 재활성 주기에 반영한다.
- 각 바위는 자기 충돌 반경 안의 적 1명에게만 데미지를 주고 비활성화된다.

## 직업별 카르마 플레이 스타일

같은 카르마라도 직업에 따라 발동 방식 또는 보정값이 달라져야 한다.

| 직업 | 기본 전투 역할 | 카르마 적용 방향 |
| --- | --- | --- |
| 전사 | 근접 다중 타격, 위험 감수 | 짧은 사거리, 높은 타격 수, 방어형 카르마 효율 증가 |
| 마법사 | 중거리 스킬 운용 | 넓은 범위, 높은 속성 데미지, 쿨다운 기반 폭딜 |
| 궁수 | 원거리 단일 타격 | 긴 사거리, 빠른 발동, 단일/체인 정밀 타격 |

### 전사

전사는 기본 공격이 다중 타격이므로 카르마도 근접 난전 보조에 맞춘다.

- 불꽃: 전방 짧은 부채꼴을 넓게 휘두른다.
- 전기: 체인 수는 낮지만 첫 타격 데미지가 높다.
- 바위: 바위 개수와 재생성 속도 보정을 받는다.

권장 보정:

| 속성 | 보정 |
| --- | --- |
| 불꽃 | 범위 +15%, 사거리 -10% |
| 전기 | 첫 대상 데미지 +20%, 체인 거리 -10% |
| 바위 | 재생성 시간 -15%, 최대 바위 수 +1은 고레벨 보너스로 제한 |

### 마법사

마법사는 속성 스킬을 가장 잘 활용하는 직업으로 둔다.

- 불꽃: 데미지와 화상 효과를 강화한다.
- 전기: 체인 수와 체인 거리 보정이 좋다.
- 바위: 방어보다는 원형 충격파 또는 궤도 범위 증가로 차별화한다.

권장 보정:

| 속성 | 보정 |
| --- | --- |
| 불꽃 | 데미지 +15%, 쿨다운 +5% |
| 전기 | 체인 거리 +20%, 체인 수 +1은 고레벨 보너스로 제한 |
| 바위 | 궤도 반경 +15%, 충돌 데미지 +10% |

### 궁수

궁수는 거리를 유지하면서 카르마가 원거리 견제를 보조해야 한다.

- 불꽃: 전방 관통형 화염탄 또는 긴 채찍 형태로 변형한다.
- 전기: 가장 긴 사거리의 체인 스킬로 둔다.
- 바위: 근접 방어막 성격을 유지하되 재생성보다 보호 안정성을 우선한다.

권장 보정:

| 속성 | 보정 |
| --- | --- |
| 불꽃 | 사거리 +25%, 범위 -10% |
| 전기 | 탐색 사거리 +25%, 데미지 -5% |
| 바위 | 바위 회전 반경 +10%, 재생성 시간 +10% |

## 카르마 드랍 확률

카르마 드랍은 두 단계로 나눈다.

1. 몬스터 처치 시 카르마 에셋이 드랍될지 결정한다.
2. 에셋 획득 시 선택 후보 3개를 생성한다.

### 기본 드랍률

| 몬스터 등급 | 카르마 에셋 드랍률 | 비고 |
| --- | --- | --- |
| 일반 | 12% | 초반 과성장을 막는다. |
| 강화 | 25% | 일반보다 체감 보상을 높인다. |
| 엘리트 | 100% | 반드시 선택 기회를 준다. |
| 보스 | 100% | 경험치 보상량을 2~3으로 높인다. |

권장 상수:

```ts
const KARMA_DROP_RATE_BY_MONSTER_GRADE = {
  normal: 0.12,
  enhanced: 0.25,
  elite: 1,
  boss: 1,
};

const KARMA_EXP_BY_DROP_SOURCE = {
  normal: 1,
  enhanced: 1,
  elite: 2,
  boss: 3,
};
```

### 후보 생성 확률

후보 생성은 현재 선택 상태에 따라 달라진다.

선택 속성이 0개:

- 전체 속성 풀에서 중복 없이 3개를 뽑는다.
- 현재는 불꽃, 전기, 바위 3개가 전부이므로 항상 3개가 나온다.

선택 속성이 1~2개:

- 이미 선택한 속성은 후보에 우선 포함한다.
- 남은 칸은 아직 선택하지 않은 속성 중 랜덤으로 채운다.
- 기존 선택 속성이 계속 성장할 수 있고, 신규 속성 선택지도 유지된다.

선택 속성이 3개:

- 후보는 선택된 3개로 고정한다.
- 선택되지 않은 속성은 더 이상 후보에 등장하지 않는다.
- 이 상태에서는 드랍된 카르마 에셋이 선택된 3종의 경험치 선택권으로만 작동한다.

추후 속성 추가 시 권장 가중치:

| 상태 | 기존 선택 속성 가중치 | 신규 속성 가중치 |
| --- | --- | --- |
| 선택 0개 | 0 | 1 |
| 선택 1개 | 2 | 1 |
| 선택 2개 | 2 | 1 |
| 선택 3개 | 1 | 0 |

## 추가 권장 방향

카르마를 자동 공격 스킬로 볼 경우, 가장 먼저 `기본 공격`과 `카르마 스킬`의 책임을 분리해야 한다.

- 기본 공격: 직업별 전투 리듬
- 카르마 스킬: 빌드별 자동 발동 효과
- 드랍률: 성장 속도 제어
- 선택 제한: 빌드 방향 고정

이 순서로 잡으면 추후 속성이 늘어나도 직업, 카르마, 드랍 밸런스를 각각 따로 조정할 수 있다.

## 2차 융합 확장 메모

2차에서는 특정 카르마들이 일정 레벨 이상에 도달하면 새로운 색상의 융합 카르마를 만든다.

예상 방향:

- 불꽃 Lv5 + 전기 Lv5 -> 붉은 번개 계열 카르마
- 전기 Lv5 + 바위 Lv5 -> 자력/자석 계열 카르마
- 바위 Lv5 + 불꽃 Lv5 -> 용암 계열 카르마

2차에서 결정할 항목:

- 융합 조건
- 융합 후 기존 카르마 유지 여부
- 융합 카르마 색상
- 융합 카르마 에셋
- 융합 후 자동 스킬 동작
- 융합 선택 UI

1차에서는 이 항목을 구현하지 않고, 데이터 구조만 추후 확장 가능하게 유지한다.
